# eMMC 5.1 工业级半导体存储产品产品手册

## 1. 产品概述
eMMC 5.1 是 车规 eMMC 5.1 的高配版本, 面向重工业与户外场景, 增加全金属外壳、
宽温工作与车规选项, 适用于冶金、矿山、化工等严苛环境.

## 2. 技术规格
- 处理器: 六核 ARM Cortex-A72 @ 2.0GHz
- 内存: 8GB LPDDR4
- 存储: 128GB eMMC + 256GB SSD
- 显示屏: 15.6 英寸电容触控, 1920x1080, 1000nit 高亮
- 接口: eMMC 5.1, HS400; 容量: 32GB/64GB/128GB
- 通信: 千兆以太网 / WiFi 6 / 4G / 5G
- 工作温度: -30°C ~ 70°C
- 防护等级: IP65
- 车规标志: Ex d IIB T4 (可选)

## 3. 合规认证
- CE / FCC / RoHS
- ATEX 车规认证 (可选型号)
- IECEx 国际车规
- ISO 9001 质量管理体系

## 4. 与 车规 eMMC 5.1 的差异
eMMC 5.1 在 车规 eMMC 5.1 基础上提升了处理性能、防护等级与通信能力,
增加 5G 与车规选项, 适用于更严苛的工业现场.
