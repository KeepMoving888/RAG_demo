# 差旅与报销管理制度

## 1. 差旅标准
| 职级 | 交通 | 住宿上限 (一线城市) | 住宿上限 (其他) |
|------|------|---------------------|------------------|
| 普通员工 | 高铁二等 / 经济舱 | 500 元/晚 | 400 元/晚 |
| 经理 | 高铁一等 / 经济舱 | 700 元/晚 | 550 元/晚 |
| 总监 | 商务座 / 公务舱 | 900 元/晚 | 700 元/晚 |

## 2. 报销流程
1. 出差前在 OA 提交出差申请;
2. 出差期间保留发票 (电子发票需打印);
3. 返回后 5 个工作日内提交报销单;
4. 直属上级审批 -> 财务审核 -> 打款.

## 3. 报销时限
- 当月费用当月报销, 跨月需总监审批
- 跨年不予报销

## 4. 招待费
- 须事前申请, 注明客户与事由
- 单次超过 2000 元需总监审批
- 严禁虚开发票

## 5. 违规处理
- 虚假报销: 全额退回 + 警告
- 二次违规: 解除劳动合同
- 涉嫌违法: 移交司法机关
