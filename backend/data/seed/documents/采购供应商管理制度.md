# 采购与供应商管理制度

## 1. 供应商准入
- 提交资质: 营业执照 / ISO 证书 / 行业资质
- 财务评估: 注册资本 / 近 3 年财报
- 现场审核: 关键供应商必须现场审核
- 试样: 小批量试用通过后纳入合格供应商名录

## 2. 采购流程
1. 需求部门提交采购申请
2. 采购部询价 / 比价 (≥3 家)
3. 金额 ≥10 万需招标
4. 合同评审 -> 签约 -> 付款

## 3. 付款条件
- 首付 30%, 货到 60%, 质保金 10% (6 个月)
- 月结 60 天 (合格供应商)

## 4. 考核
- 季度考核: 质量 / 交期 / 服务
- 年度评级: A / B / C / D
- D 级淘汰, A 级优先采购

## 5. 廉洁
- 采购人员每年签署廉洁承诺
- 严禁收受供应商回扣
- 举报有奖
