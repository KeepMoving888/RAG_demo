# LPDDR4X DRAM 桌面级产品手册

## 1. 产品概述
LPDDR4X 是面向桌面级轻薄终端的低功耗 DRAM 模组, 在 LPDDR4 基础上将
VDD2L 电压降至 0.6V, 显著降低功耗, 适用于一体机、迷你主机与轻薄笔记本等
桌面级半导体存储产品.

## 2. 技术规格
- 颗粒类型: LPDDR4X SDRAM
- 工作电压: VDD1 = 1.1V, VDD2L = 0.6V
- 接口: 16-bit 双通道
- 数据速率: LPDDR4X-4266 (4266 MT/s)
- 容量: 4Gb / 8Gb / 16Gb
- 封装: 200-ball FBGA (12 x 14.5 mm)
- 工作温度: 0°C ~ 85°C (商业级) / -40°C ~ 95°C (车规级)
- 刷新: 8192 周期 / 32ms (TC ≤ 85°C)

## 3. 合规认证
- JEDEC JESD209-4 (LPDDR4 标准)
- CE / FCC / RoHS / REACH
- AEC-Q100 车规认证 (车规型号)
- ISO 9001 质量管理体系

## 4. 适用场景
- 桌面级一体机与迷你主机
- 轻薄笔记本与平板
- 车载信息娱乐系统 (IVI)
- 边缘计算网关
