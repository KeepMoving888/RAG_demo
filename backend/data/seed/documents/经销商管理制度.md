# 经销商授权与管理制度

## 1. 授权等级
- 一级经销商: 区域独家, 年度采购 ≥500 台
- 二级经销商: 区域内多家, 年度采购 ≥100 台
- 行业经销商: 行业内独家, 年度采购 ≥200 台

## 2. 授权申请
1. 提交营业执照 / 法人身份 / 公司简介
2. 销售部审核 (5 个工作日)
3. 签署授权协议
4. 缴纳保证金 (一级 50 万, 二级 10 万)

## 3. 考核
- 季度考核: 销售达成率 / 客户满意度 / 库存周转
- 年度考核: 综合评分, 决定授权续签
- 连续 2 个季度未达成: 取消授权

## 4. 价格管控
- 严格执行价格政策, 不得低价倾销
- 跨区域销售需报备
- 违规一次警告, 二次罚款, 三次取消授权

## 5. 支持
- 培训: 每季度产品与技术培训
- 物料: 销售手册 / 演示机 / 备件
- 售后: 优先处理经销商售后工单
