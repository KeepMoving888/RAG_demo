# 关于跨境电商平台合规检查的通知

## 1. 背景
近期亚马逊、速卖通、Shopee 等平台加强合规检查, 多家店铺因资质缺失被下架,
现开展全员自查.

## 2. 平台要求
### 2.1 亚马逊
- CE / UKCA 合规文件上传;
- EPR 注册号 (德/法/西);
- GPSR 制造商与责任人信息;
- 含电池产品提供电池指令合规声明.

### 2.2 速卖通
- 原产地证明;
- 知识产权授权书;
- 电子电器 CCC 或 CE;
- 食品接触材料检测报告.

### 2.3 Shopee
- 东南亚各国 SNI / PSB / TISI 认证;
- 化妆品通知号;
- 食品 HFIS 注册;
- 标签合规 (目的国语言).

## 3. 自查清单
1. listing 是否标注认证编号;
2. 平台后台资质是否在有效期内;
3. 产品标签是否包含目的国语言;
4. 是否上传 DoC 与测试报告;
5. EPR 注册号是否覆盖全部销售国;
6. 知识产权是否存在侵权风险.

## 4. 整改要求
- 自查发现缺失资质 7 个工作日内补齐;
- 暂时无法补齐的 SKU 主动下架, 避免平台处罚;
- 整改完成情况由 SALES 部门汇总报 CMP.

## 5. 时间安排
- 自查: 通知发布后 2 周内完成;
- 整改: 4 周内完成;
- 复核: CMP 部门抽检 20% SKU.

## 6. 罚则
因未及时自查导致店铺被处罚的, 责任人承担相应损失.
