# NOR Flash 闪存芯片产品手册

## 1. 产品概述
本产品为 NOR Flash 闪存芯片, 采用 55nm 制程 SPI 接口, 具备高可靠性与
快速随机读取能力, 适用于车载仪表、工控 BIOS、物联网固件存储等场景.

## 2. 技术原理
- 制程: 55nm NOR 浮栅工艺;
- 接口: SPI / Dual-SPI / Quad-SPI / QPI;
- 容量: 32Mb / 64Mb / 128Mb / 256Mb / 512Mb;
- 读取速度: Quad-SPI 最高 104MHz, ≈ 416 Mbit/s;
- 编程粒度: 256 Byte Page Program;
- 擦除粒度: 4KB Sector / 32KB Block / 64KB Block / 全片擦除.

## 3. 应用场景
- 车载 MCU 启动代码存储 (车规 AEC-Q100);
- 工业控制 BIOS / 固件存储;
- IoT 设备 OTA 备份区;
- 通信基带固件存储;
- 安防设备引导加载程序.

## 4. 车规合规认证
- AEC-Q100 Grade 3 (-40°C ~ 85°C) 或 Grade 2 (-40°C ~ 105°C);
- ISO 26262 ASIL-B 功能安全 (部分型号);
- IATF 16949 质量管理体系认证;
- PPAP 生产件批准文件;
- 标签: 含批次号、生产周码、车规标识.

## 5. 数据保持与耐久度
- 数据保持: 20 年 (25°C);
- 擦写次数: ≥10 万次 (per Sector);
- 数据保持: 10 年 (85°C);
- 擦写次数: ≥1 万次 (per Sector, 高温场景);
- 内置 ECC 与坏块管理.

## 6. 售后与质保
- 标准质保 36 个月, 车规型号 60 个月;
- 提供失效分析 (FA) 报告服务;
- 跨境销售须提供目的国 RoHS / REACH 报告;
- 批次追溯通过晶圆 ID 与封装序列号双码绑定.

## 7. 安全提示
芯片对静电 (ESD) 敏感, 操作须佩戴防静电手环并使用防静电包装;
焊接温度峰值 ≤260°C, 持续时间 ≤10 秒, 避免热应力导致封装开裂.
