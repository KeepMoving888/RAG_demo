# RoHS 2.0 符合性声明

## 1. 法规依据
- 指令 2011/65/EU (RoHS 2.0)
- 委员会授权指令 (EU) 2015/863 (邻苯二甲酸酯修订)

## 2. 声明范围
本声明覆盖半导体存储产品 LPDDR4X/车规 eMMC 5.1/eMMC 5.1 全系列及其配件, 属于指令附录 I
第 1 类 (大型家用电器) 与第 6 类 (小型通信设备) 范畴.

## 3. 有害物质清单与限值
| 物质 | 限值 (均质材料中) |
|------|------------------|
| 铅 (Pb) | 0.1% |
| 镉 (Cd) | 0.01% |
| 汞 (Hg) | 0.1% |
| 六价铬 (Cr6+) | 0.1% |
| 多溴联苯 (PBB) | 0.1% |
| 多溴二苯醚 (PBDE) | 0.1% |
| 邻苯二甲酸二酯 (DEHP/BBP/DBP/DIBP) | 0.1% |

## 4. 豁免项引用
- 附录 III 豁免 6(c): 铜合金中铅含量 ≤4%;
- 附录 III 豁免 7(a): 高温熔融焊料中铅;
- 豁免到期前持续有效, 到期后 12-18 个月宽限期内可继续供货.

## 5. 技术文件
依据 EN 50581 / IEC 63000, 收集物料声明、检测报告 (XRF + 化学湿法)、
供应链声明, 形成技术文件并随 DoC 保存 10 年.

## 6. CE 标识
RoHS 符合性作为 CE 标识前置条件, 与 EMC/LVD 一并评估.
