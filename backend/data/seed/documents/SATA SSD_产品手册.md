# SATA 接口 SSD 固态硬盘产品手册

## 1. 产品概述
本产品为 2.5 英寸 SATA III 接口 SSD 固态硬盘, 采用 3D TLC NAND Flash 与
自研主控, 适用于桌面台式机、笔记本与轻负载服务器, 兼容 SATA 6Gb/s 串行总线.

## 2. 兼容平台
- 主流桌面平台 (Intel 100/200/300/400/500 系列芯片组);
- 笔记本 SATA 光驱位 / 硬盘位;
- 服务器 SATA 接口直连或 RAID 卡;
- 不兼容 PCIe NVMe 协议插槽 (总线协议不同).

## 3. 安装方式
- 2.5 英寸 7mm 标准外形, 直接装入硬盘位;
- 笔记本端: SATA 数据与电源一体接口, 即插即用;
- 桌面端: 配合 3.5 英寸支架安装;
- 安装时长: 3-5 分钟, 无需额外驱动.

## 4. 认证要求
- CE / FCC / RoHS / REACH;
- BSMI 台湾认证;
- UKCA 英国合规标志;
- 部分行业要求 AES-256 加密认证 (TCG Opal).

## 5. 技术规格
- 接口: SATA III 6Gb/s, 向下兼容 SATA II/I;
- 容量: 120GB / 240GB / 480GB / 960GB / 1.92TB;
- 顺序读取: ≤560 MB/s;
- 顺序写入: ≤530 MB/s;
- 4K 随机读取: ≤95K IOPS;
- 4K 随机写入: ≤90K IOPS;
- 主控: 自研 SM2259XT;
- NAND: 3D TLC, 128 层堆叠;
- DRAM 缓存: 256MB (480GB 及以上容量);
- 工作温度: 0°C ~ 70°C;
- 存储温度: -40°C ~ 85°C;
- 防震动: 1500G/0.5ms;
- MTBF: 150 万小时;
- 寿命: 240GB ≈ 100 TBW, 480GB ≈ 200 TBW.

## 6. 售后与质保
- 质保 36 个月, 非人为损坏免费换新;
- 固件 OTA 升级, 持续优化兼容性与性能;
- 7 天无理由退货 (包装完整, 已通电需扣折旧费);
- 提供专属 SSD 健康度监测工具.

## 7. 合规提示
跨境销售须确认目标市场电子产品合规要求, 欧盟市场需提供 EPR 注册号与
WEEE 回收标识, 美国加州需满足 Prop 65 警示标签要求.
