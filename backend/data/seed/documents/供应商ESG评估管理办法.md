# 供应商 ESG 评估管理办法

## 1. 目的
建立供应商环境、社会与治理 (ESG) 三维评估体系, 推动供应链可持续发展,
降低合规与声誉风险.

## 2. 适用范围
适用于所有合格供应商名录内供应商及年度采购额 ≥100 万元的关键候选供应商.

## 3. 评估维度
### 3.1 环境 (E)
- ISO 14001 体系认证;
- 碳排放披露与减排目标;
- 水资源与能源消耗;
- 危险废弃物处置合规.

### 3.2 社会 (S)
- BSCI/SA8000 社会责任审核;
- 工时与薪酬合规;
- 职业健康安全;
- 童工与强迫劳动零容忍.

### 3.3 治理 (G)
- 反腐败与商业道德;
- 数据安全与隐私;
- 供应链透明度;
- 知识产权保护.

## 4. 评分标准
- 三维各 100 分, 权重 E:30 / S:40 / G:30;
- 综合得分 ≥85: A 级, 优先采购;
- 70-84: B 级, 正常采购;
- 60-69: C 级, 限期整改;
- <60: D 级, 触发淘汰.

## 5. 评估流程
1. 供应商提交 ESG 自评问卷与佐证材料;
2. 采购部初审;
3. 第三方机构或 CMP 部门现场核查;
4. 出具评估报告并反馈供应商.

## 6. 淘汰机制
- 连续两次评估 C 级启动整改;
- 评估 D 级或发生重大 ESG 事故立即冻结订单, 启动退出流程;
- 退出须 90 天内完成备选切换与库存消化.
