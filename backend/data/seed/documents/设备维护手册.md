# 半导体存储产品维护手册

## 1. 日常维护
- 屏幕: 用专用清洁布擦拭, 禁用酒精
- NAND 颗粒: 检查焊接点, 检测坏块
- 散热孔: 每月清理灰尘

## 2. 月度维护
- 检查系统日志是否有异常告警
- 执行 SMART 健康检测
- 检查电源线 / 网线磨损

## 3. 季度维护
- 升级最新固件
- 数据库备份
- 触控屏校准

## 4. 年度维护
- 整机除尘
- 电池 (如有) 健康度检测
- 关键部件寿命评估

## 5. 故障代码
| 代码 | 含义 | 处理 |
|------|------|------|
| E001 | eMMC 无法识别 | 检查焊接 / 重新上电 |
| E002 | 网络断开 | 检查网线 / 重启路由 |
| E003 | 存储空间不足 | 清理日志 / 扩容 |
| E004 | 系统温度过高 | 检查散热 / 停机降温 |
| E005 | 显示屏无信号 | 检查排线 / 更换屏幕 |
