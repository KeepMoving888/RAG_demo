# 车规 eMMC 5.1 半导体存储产品产品手册

## 1. 产品概述
车规 eMMC 5.1 是面向车载应用的 NAND 闪存芯片, 符合 AEC-Q100 Grade 3 标准,
集成控制器与 NAND die, 提供高可靠性存储, 适用于车载信息娱乐、ADAS 数据记录与
工业控制等高可靠性场景.

## 2. 技术规格
- 处理器: 四核 ARM Cortex-A55 @ 1.8GHz
- 内存: 4GB LPDDR4
- 存储: 64GB eMMC
- 显示屏: 15.6 英寸电容触控, 1920x1080
- 接口: eMMC 5.1, HS400
- 通信: 千兆以太网 / WiFi 6 / 蓝牙 5.0
- 工作温度: -10°C ~ 50°C
- 防护等级: IP54

## 3. 合规认证
- CE / FCC / RoHS
- CCC 国内强制认证
- ISO 9001 质量管理体系

## 4. 标准配置
| 配件 | 数量 | 备注 |
|------|------|------|
| 主机 | 1 | - |
| 电源适配器 | 1 | 24V/3A |
| NAND Die | 4 | 3D TLC 256Gb |
| 安装支架 | 1 | VESA 标准 |

## 5. 安装步骤
1. 固定安装支架到墙面或立柱;
2. 主机挂载到支架并锁紧;
3. 连接电源与网线;
4. 开机进入初始化向导, 配置 WiFi 与服务器地址.
