# 半导体存储产品术语速查

## 存储颗粒类型
- NAND Flash: 非易失性闪存, 用于 SSD / eMMC / UFS / MicroSD, 按单元位数分 SLC / MLC / TLC / QLC
- NOR Flash: 随机读取快, 用于代码存储与固件引导
- DRAM: 动态随机存储, 易失性, 用于主存与缓存
- LPDDR: 低功耗 DRAM 系列 (LPDDR4 / 4X / 5), 面向移动与桌面级终端

## 单元类型 (NAND)
- SLC: 1 bit/cell, 寿命最长 (~10 万 P/E cycle), 用于工控与车规
- MLC: 2 bit/cell, 寿命中等 (~3000 P/E cycle)
- TLC: 3 bit/cell, 寿命 ~1000 P/E cycle, 消费级主流
- QLC: 4 bit/cell, 寿命 ~100 P/E cycle, 大容量低成本

## 存储器件
- SSD: 固态硬盘, SATA / PCIe 接口, 用于桌面与服务器存储
- eMMC: 嵌入式多媒体卡, BGA 封装, 用于中低端移动与物联网
- UFS: 通用闪存存储, 串行高速接口, 用于中高端手机与车机
- MCP: 多芯片封装, 集成 DRAM + NAND, 节省 PCB 面积

## 可靠性与寿命
- P/E Cycle: 擦写循环次数, 衡量 NAND 寿命
- TBW: 总写入字节数 (Terabytes Written), SSD 保修指标
- HTOL: 高温工作寿命测试, 加速老化评估可靠性
- AEC-Q100: 车规集成电路可靠性标准
- Bad Block: 坏块, 出厂或使用中产生的不可用块
- ECC: 纠错编码, BCH / LDPC 纠正 NAND 读写错误

## 闪存管理技术
- Wear Leveling: 磨损均衡, 均匀分配擦写, 延长寿命
- TRIM: 操作系统通知 SSD 回收无效数据块
- FTL: 闪存转换层, 映射逻辑地址到物理块
- Garbage Collection (GC): 垃圾回收, 整理有效数据释放空闲块
- Over-Provisioning (OP): 预留空间, 提升性能与寿命

## 性能指标
- IOPS: 每秒输入输出次数, 衡量随机读写性能
- 顺序读写: 大文件连续传输速率 (MB/s)
- 写入放大 (WA): 实际写入闪存 / 主机写入量
