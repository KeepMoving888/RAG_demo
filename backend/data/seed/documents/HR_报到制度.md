# 新员工报到管理制度

## 1. 报到准备
- HR 提前 3 个工作日发送报到通知
- 候选人需提供: 身份证 / 学历证明 / 体检报告 / 离职证明 / 银行卡

## 2. 报到当天
- 上午: 签订劳动合同, 领取工牌与办公用品
- 下午: IT 配置账号与设备, HR 培训公司制度
- 第二天: 部门报到, 导师对接

## 3. 试用期
- 试用期 3 个月 (关键岗位 6 个月)
- 试用期薪资为转正薪资的 80%
- 试用期满前 7 天进行转正答辩

## 4. 福利
- 五险一金: 报到当月缴纳
- 补充医疗: 转正后生效
- 年假: 按司龄累计, 5-15 天
- 节日福利: 春节 / 中秋 / 端午

## 5. 保密协议
- 报到当天签署保密协议
- 涉密岗位额外签署竞业协议
- 离职后 2 年内不得加入直接竞争对手
