# 研发项目管理制度

## 1. 立项
- 项目发起人提交立项书 (市场背景 / 技术方案 / 资源需求 / 里程碑)
- 研发总监 + 产品总监联合评审
- 立项通过后成立项目组, 任命 PM

## 2. 开发流程
- 需求评审 -> 设计评审 -> 编码 -> 代码评审 -> 测试 -> 发布
- 每个阶段需产出对应文档, 归档到 wiki

## 3. 里程碑
- 立项后 30 天内完成需求与设计
- 编码阶段每周提交进度报告
- 测试阶段必须覆盖所有 P0/P1 用例

## 4. 变更管理
- 需求变更: PM 评估影响, 项目组评审
- 里程碑变更: 需研发总监审批
- 人员调整: 需资源经理协调

## 5. 结项
- 项目交付后 30 天内结项
- 结项需提供: 总结报告 / 经验教训 / 资产清单
- 项目奖金按结项评分发放
