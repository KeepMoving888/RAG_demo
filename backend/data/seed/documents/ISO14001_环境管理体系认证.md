# ISO 14001:2015 环境管理体系认证文件

## 1. 认证信息
- 证书编号: SGSCN-2024-EMS-00521
- 认证标准: ISO 14001:2015
- 认证机构: SGS 通标标准技术服务有限公司
- 认证范围: 半导体存储产品及相关产品的研发、生产活动所涉及的环境管理
- 有效期至: 2027-08-20

## 2. 环境方针
以绿色设计、清洁生产、节能降耗、污染预防为方针, 持续改进环境绩效,
遵守适用法律法规与其他要求, 提升全员环境意识.

## 3. 环境目标与指标
- 单位产品能耗较基准年下降 8%;
- 危险废弃物合规处置率 100%;
- 一般工业固废综合利用率 ≥90%;
- 包装材料可回收比例 ≥80%.

## 4. 废弃物管理
- 生活垃圾: 分类收集, 环卫部门清运;
- 一般工业固废: 回收利用, 台账记录;
- 危险废弃物 (废墨盒、废电池、废溶剂): 交由具备 HW 资质的处置单位转移处置,
  执行联单制度;
- 废弃电子元器件: 纳入 WEEE 流向管理.

## 5. 环境因素识别与合规评价
每年开展环境因素识别与重大环境因素评价, 每季度进行合规性评价,
形成记录并归档.
