# 半导体存储产品售后常见问题 FAQ

## Q1: 车规 eMMC 5.1 开机黑屏怎么办?
A: 请按以下顺序排查:
1. 检查电源适配器指示灯是否点亮;
2. 用万用表测量电源输出是否为 24V;
3. 长按电源键 10 秒强制重启;
4. 若仍黑屏, 联系售后更换显示屏排线.

## Q2: eMMC 读写速度变慢怎么处理?
A: 常见原因与处理:
1. 检查 TRIM 是否开启, 未开启将影响垃圾回收效率;
2. 是否触发磨损均衡, 大量擦写后主控会进行后台搬运;
3. 温度过高触发降频保护, 检查散热与工作温度;
4. 预留空间 (OP) 不足, 考虑增加 Over-Provisioning.

## Q3: eMMC 5.1 车规型号可以在户外使用吗?
A: 可以. 车规型号同时具备 IP65 防护, 户外使用需加装遮阳罩避免阳光直射屏幕.

## Q4: 设备无法连接到服务器怎么办?
A: 排查步骤:
1. 检查网线是否插好, 网口指示灯是否正常;
2. 在终端 ping 服务器 IP;
3. 检查服务器防火墙是否放行端口;
4. 确认终端与服务器时间是否同步 (证书校验依赖).

## Q5: 保修期是多久?
A: 主机 2 年, 配件 1 年. 车规型号主机保修 3 年.
人为损坏与不可抗力不在保修范围.

## Q6: 如何申请售后上门?
A: 致电 400-xxx-xxxx 或登录售后门户提交工单, 提供设备序列号 (SN) 与故障描述.
